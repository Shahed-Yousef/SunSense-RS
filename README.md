# SunSense-RS

SunSense-RS is a Python-based solar panel monitoring system designed to analyze voltage and power data under Kuwait's weather conditions. The system can load or generate sensor data, calculate statistics, monitor operating thresholds, compare different scenarios, and visualize results using graphs.

## Features

- Generate simulated solar panel sensor data
- Load voltage and power data from a CSV file
- Display and analyze recorded data
- Calculate basic statistics
- Monitor normal, warning, and critical operating conditions
- Compare solar panel performance under different weather conditions
- Visualize data using graphs

## Technologies Used

- Python
- Jupyter Notebook
- CSV
- Matplotlib

## Project Files

- `SunSense_RS.ipynb` – Main Python program
- `data.csv` – Sample voltage and power data
- `SunSense_RS_Project_Report.pdf` – Full project report

## Project Context

Developed as a university programming project at Abdullah Al Salem University, combining Python programming with an application related to solar energy systems.
